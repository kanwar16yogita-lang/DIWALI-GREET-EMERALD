# Luxora | A Diwali Wish 2026

A lightweight, mobile-first festive greeting website for **Luxora Interiors × Luxora Lifestyles**.

## What is included
- Original uploaded Luxora Lifestyles gold logo used unchanged (`assets/luxora-lifestyles-logo.png`).
- Original provided Luxora staff photograph with green Luxora shirts (`assets/luxora-team-diwali.png`).
- Short illustrated animation of a team raising their hands in namaste, transitioning into the real team photograph. The staff illustration is stylized; the real staff image is not manipulated.
- Emerald velvet background, gold particles, floating diyas, shimmering ornaments, responsive typography, interaction buttons and replay.
- No RSVP form, tracking backend, cookies, secrets or Google Sheet connection.

## Preview locally
Open `index.html` in Chrome or another browser. For the full web experience, serve the directory via a local server or deploy to a static web host.

## Deploy to Vercel
1. Extract the ZIP.
2. In GitHub, create a **new public repository** and upload the contents of this folder (not the ZIP itself). Ensure `index.html` and the `assets` folder are at repository root.
3. In Vercel, choose **Add New → Project**, import this repository, use **Other** framework, **Root Directory `./`** and no custom build command.
4. Click **Deploy** and share your resulting Vercel URL.

All text is editable in `index.html`. No environment variables or backend integrations are required.
